# pi-github-theme

GitHub Dark Default theme for the [pi coding agent](https://github.com/earendil-works/pi-mono) TUI.

## Install

```bash
pi install github.com/praffiii/my-pi-setup/packages/github-theme
```

## Use

Select `github-dark-default` from `/settings`, or set it in your pi settings:

```json
{
  "theme": "github-dark-default"
}
```
